# 기울기 실험실

## 대칭 할선의 기울기와 극한 탐구

**탐구 질문: 대칭 할선의 기울기가 하나의 값으로 수렴하면, 그 점에서 항상 미분가능할까?**

그래프 위의 점을 마우스나 터치로 직접 움직이며 평균변화율, 극한,
미분계수의 관계를 살펴보는 한국어 수학 탐구 프로그램입니다.
기존 프로젝트의 네 함수와 탐구 주제를 유지하면서 조작 방식과 설명을 다시 구성했습니다.

## 1. 가장 빠른 실행 방법

### 설치 없이 실행

`secant_lab.html`을 다운로드한 뒤 Chrome 또는 Edge에서 엽니다.
HTML 안에 그래프 코드와 스타일이 모두 포함되어 있어 인터넷 연결 없이도 사용할 수 있습니다.

### Windows에서 Streamlit으로 실행

Python 3.12를 권장합니다. 실행 의존성은 검증한 Streamlit 1.67.0으로 고정했습니다.

1. `math_project_complete.zip`을 압축 해제합니다.
2. 압축을 푼 폴더를 파일 탐색기로 엽니다.
3. 파일 탐색기 주소창에 `cmd`를 입력하고 Enter를 누릅니다.
4. 아래 두 명령을 차례대로 실행합니다.

```bat
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

`python` 명령을 찾지 못하면 `py -m pip install -r requirements.txt`와
`py -m streamlit run app.py`를 사용합니다.
진입 파일의 이름은 **app.py**입니다.

### 기존 GitHub / Streamlit Cloud 앱에 적용

1. GitHub의 `jcl090312/math` 저장소에서 `app.py`를 새 파일로 교체합니다.
2. `requirements.txt`도 함께 교체합니다.
3. 설명을 맞추려면 `README.md`, `log.md`도 함께 교체합니다.
4. 변경을 `main` 브랜치에 커밋합니다.
5. Streamlit Cloud의 앱 설정에서 저장소 `jcl090312/math`, 브랜치 `main`,
   실행 파일 `app.py`가 맞는지 확인합니다.
6. 배포가 끝난 뒤 앱을 새로고침합니다. 이전 화면이 남으면 `Ctrl + F5`를 누릅니다.

실행에 필요한 파일은 `app.py`, `requirements.txt` 두 개입니다.
`app.py`에 화면 코드가 포함되어 있으므로 `dist` 폴더를 추가로 업로드할 필요가 없습니다.
기존의 NumPy, pandas, Plotly 의존성은 이번 실행 파일에서 사용하지 않습니다.
메모는 사용하는 브라우저에 저장되며 다른 기기와 자동 동기화되지 않습니다.

## 2. 점을 직접 움직이는 방법

| 조작 | 변화 |
| --- | --- |
| 가운데 점 A를 좌우로 드래그 | 기준점 a가 바뀌며 세 점이 함수 위에서 함께 이동 |
| 왼쪽 점 L 또는 오른쪽 점 R을 드래그 | 거리 h가 바뀌며 반대쪽 점도 a에서 같은 거리로 이동 |
| a와 h 숫자 입력 | 정확한 실험 조건 설정 |
| h를 절반으로 줄이기 | 픽셀 단위 드래그로 구분하기 어려운 작은 h 관찰 |
| h → 0 재생 | 양쪽 점이 기준점에 가까워지는 과정 관찰 |
| 원점 / 반례 설정 | 미분 불가능한 지점을 정확하게 선택 |
| 점 선택 후 방향키 | 마우스 없이 점을 이동; 점이 겹친 경우에도 사용 |

점의 세로 좌표는 선택한 함수의 함숫값으로 결정됩니다.
그래프 밖의 임의의 위치로 점을 옮기지는 않습니다.
양끝점은 **x좌표의 거리**가 같으며, y좌표는 각각 함수에 대입해 구합니다.

h는 0보다 크게 유지됩니다. h=0을 대입하는 것과 h가 0에 가까워질 때의 극한은 다릅니다.
미분가능성 안내는 알려진 함수의 정확한 수학적 결과를 사용합니다.
현재 두 기울기가 비슷해 보인다는 이유로 미분가능하다고 판정하지 않습니다.

## 3. 세 기울기의 정의

기준점과 양끝점은 다음과 같습니다.

\[
A=(a,f(a)),\quad L=(a-h,f(a-h)),\quad R=(a+h,f(a+h)),\quad h>0
\]

왼쪽 평균변화율과 오른쪽 평균변화율:

\[
L_h(a)=\frac{f(a)-f(a-h)}h,\qquad
R_h(a)=\frac{f(a+h)-f(a)}h
\]

대칭 할선의 기울기:

\[
S_h(a)=\frac{f(a+h)-f(a-h)}{2h}
=\frac{L_h(a)+R_h(a)}2
\]

대칭 할선은 **L과 R을 잇는 선**입니다. 일반적으로 가운데 점 A를 지나지 않습니다.
실제 접선은 미분계수가 존재할 때만 표시하며, A를 지납니다.

\[
\text{대칭 할선: }y=f(a-h)+S_h(a)(x-a+h)
\]

\[
\text{접선: }y=f(a)+f'(a)(x-a)
\]

## 4. 네 함수의 비교

| 함수 | 대칭 할선의 기울기 | h → 0⁺의 극한 | 미분가능성 |
| --- | --- | --- | --- |
| f(x)=x² | 2a | 2a | 모든 실수에서 미분가능 |
| f(x)=x³ | 3a²+h² | 3a² | 모든 실수에서 미분가능 |
| f(x)=\|x\|, a=0 | 0 | 0 | 원점에서 미분 불가능: 왼쪽 −1, 오른쪽 1 |
| f(x)=x (x<0), x² (x≥0), a=0 | (1+h)/2 | 1/2 | 원점에서 미분 불가능: 왼쪽 1, 오른쪽 0 |

### 이차함수

\[
L_h=2a-h,\quad R_h=2a+h,\quad S_h=2a
\]

대칭 기울기는 h가 작아질 때만 2a에 가까워지는 것이 아니라,
**모든 h>0에서 이미 정확히 2a**입니다.
그래도 대칭 할선과 접선의 위치는 일반적으로 다릅니다.
예를 들어 a=1, h=1일 때 대칭 할선은 y=2x, 접선은 y=2x−1입니다.

### 삼차함수

\[
L_h=3a^2-3ah+h^2,\quad R_h=3a^2+3ah+h^2,\quad S_h=3a^2+h^2
\]

대칭 기울기와 미분계수의 차이는 h²입니다.
h를 절반으로 줄이면 그 차이는 1/4로 줄어듭니다.

### 절댓값 함수의 원점

\[
L_h=-1,\quad R_h=1,\quad S_h=0
\]

대칭 할선은 y=h이고, 기울기는 항상 0입니다.
그러나 왼쪽과 오른쪽 평균변화율이 서로 다른 값으로 수렴하므로 미분계수는 존재하지 않습니다.
a>0에서는 미분계수가 1, a<0에서는 −1입니다.

### 구간별 함수의 원점

\[
f(x)=\begin{cases}x&x<0\\x^2&x\ge0\end{cases}
\]

\[
L_h=1,\quad R_h=h,\quad S_h=(1+h)/2
\]

대칭 기울기는 1/2로 수렴하지만 좌우 극한은 각각 1과 0입니다.
따라서 원점에서 미분 불가능합니다.
a<0에서는 미분계수 1, a>0에서는 2a입니다.

## 5. 핵심 결론과 탐구 범위

f가 a에서 미분가능하면 대칭 할선 기울기의 극한도 존재하며 그 값은 f′(a)와 같습니다.
하지만 대칭 할선 기울기의 극한이 존재한다는 사실만으로 미분가능성을 보장할 수 없습니다.

이 프로그램은 유한한 개수의 h에서 값을 계산하고 시각화합니다.
그래프와 표는 관찰을 돕는 도구이며, 극한의 존재에 대한 증명을 대신하지 않습니다.
위 식의 전개와 좌우 극한 비교로 결론을 설명해야 합니다.

## 6. 탐구 순서 제안

1. x², a=1, h=1에서 왼쪽·오른쪽·대칭 기울기를 비교합니다.
2. h를 절반으로 여러 번 줄이고, 변하는 값과 변하지 않는 값을 구분합니다.
3. x³에서도 같은 실험을 하고, 대칭 기울기의 오차가 어떻게 줄어드는지 확인합니다.
4. |x|의 원점에서 같은 실험을 하여 앞선 예상이 항상 맞는지 검토합니다.
5. 구간별 함수의 원점에서 다른 값으로 수렴하는 반례를 추가로 확인합니다.
6. CSV와 그래프 SVG를 저장하고, 자신의 관찰과 해석을 log.md에 기록합니다.

## 7. 파일 구성 및 개발

| 파일 | 역할 |
| --- | --- |
| app.py | Streamlit에서 바로 실행하는 단일 파일 |
| requirements.txt | Streamlit 의존성 |
| secant_lab.html | 설치 없이 브라우저에서 실행하는 단일 HTML |
| README.md | 실행 안내와 수학적 설명 |
| log.md | 탐구 기록 양식 및 해석 예시 |
| dist/ | 배포용 웹 화면의 원본 파일 |
| tests/math-core.test.cjs | 공식·반례·수치 안정성 검사 |
| tools/build_streamlit.py | 웹 원본으로 app.py, 단일 HTML, ZIP 생성 |

웹 화면은 외부 그래프 CDN 없이 SVG와 Pointer Events를 사용합니다.
점을 움직일 때 계산과 화면 갱신은 브라우저 안에서 이루어집니다.

개발자가 원본을 수정한 경우:

```bash
node --test tests/math-core.test.cjs
python tools/build_streamlit.py
python -m streamlit run app.py
```
