# 📐 수학 × 정보 융합 주제탐구
## 세 할선의 기울기 비교를 통한 평균변화율과 미분계수의 관계 탐구

## 1. 프로젝트 소개

이 프로젝트는 고등학교 2학년 수학 과목인 **미적분Ⅰ**에서 배우는 평균변화율과 미분계수의 관계를 정보 기술과 결합하여 탐구하기 위해 제작되었습니다.

함수 \(f(x)=x^2\)를 대상으로 하나의 기준점과 세 개의 이동점을 설정하고, 각 이동점을 기준점과 연결하여 만들어지는 세 할선의 기울기를 비교합니다.

Python과 Streamlit을 활용하여 수학적 계산을 실시간으로 시각화하고, 이동 거리 \(h\)를 변화시키면서 세 할선의 기울기가 미분계수에 가까워지는 과정을 분석할 수 있도록 제작하였습니다.

## 2. 탐구 동기

미적분Ⅰ에서 평균변화율과 미분계수를 학습하면서 두 점 사이의 평균변화율이 어떻게 한 점에서의 순간변화율로 연결되는지 궁금해졌습니다.

기존에는 두 점을 연결한 하나의 할선과 접선을 비교하는 방식으로 이해했지만, 하나의 기준점에 서로 다른 세 개의 이동점을 연결한다면 평균변화율의 변화를 더욱 구체적으로 비교할 수 있을 것이라고 생각했습니다.

이에 따라 세 할선의 기울기를 동시에 계산하고, 이동 거리 \(h\)를 변화시키면서 각각의 기울기가 미분계수에 접근하는 과정을 프로그램으로 구현하였습니다.

## 3. 핵심 탐구 질문

- 하나의 기준점에 세 개의 이동점을 연결하면 각 할선의 기울기는 어떻게 달라질까?
- 이동 거리 \(h\)가 작아질수록 세 할선의 기울기는 어떻게 변화할까?
- 서로 다른 세 할선의 기울기가 하나의 미분계수에 가까워질 수 있을까?
- 왼쪽과 오른쪽에서 접근할 때 결과에는 어떤 차이가 있을까?
- 세 할선과 미분계수 사이의 오차에는 어떤 수학적 규칙이 있을까?

## 4. 수학적 원리

탐구 대상 함수는 다음과 같습니다.

\[
f(x)=x^2
\]

기준점은 \(A(a,f(a))\)이며, 세 이동점은 접근 방향에 따라 다음과 같이 설정합니다.

\[
a+sh,\quad a+2sh,\quad a+3sh
\]

여기서 \(s=1\)은 오른쪽 접근, \(s=-1\)은 왼쪽 접근을 의미합니다.

세 할선의 기울기는 다음과 같습니다.

\[
m_1=2a+sh
\]

\[
m_2=2a+2sh
\]

\[
m_3=2a+3sh
\]

기준점에서의 미분계수는

\[
f'(a)=2a
\]

입니다.

따라서 세 할선과 미분계수 사이의 절대 오차는 각각 다음과 같습니다.

\[
|m_1-f'(a)|=h
\]

\[
|m_2-f'(a)|=2h
\]

\[
|m_3-f'(a)|=3h
\]

이동 거리 \(h\)가 0에 가까워질수록 세 할선의 기울기가 모두 미분계수에 가까워지는 원리를 확인할 수 있습니다.

## 5. 주요 기능

| 기능 | 설명 |
|---|---|
| 기준점 설정 | 슬라이더를 통해 기준점 a 변경 |
| 이동 거리 조절 | h의 크기를 실시간으로 변경 |
| 접근 방향 선택 | 왼쪽 및 오른쪽 접근 비교 |
| 세 할선 시각화 | 세 할선과 이동점 표시 |
| 접선 표시 | 실제 미분계수에 해당하는 접선 표시 |
| 기울기 비교 | 세 할선의 평균변화율 계산 |
| 오차 분석 | 미분계수와 각 할선의 기울기 차이 계산 |
| 수렴 분석 | 여러 h 값에 따른 기울기 비교 |
| 변화 그래프 | 기울기 변화 및 오차 변화 시각화 |
| 데이터 다운로드 | 분석 결과를 CSV 파일로 저장 |

## 6. 사용 기술

- **Python:** 수학적 계산 및 데이터 처리
- **Streamlit:** 웹 기반 탐구 프로그램 제작
- **NumPy:** 수치 계산 및 그래프 데이터 생성
- **Pandas:** 분석 결과 정리 및 표 제작
- **Plotly:** 함수, 할선, 접선 및 분석 그래프 시각화
- **GitHub:** 프로젝트 코드 관리 및 공유
- **Streamlit Cloud:** 웹 프로그램 배포
