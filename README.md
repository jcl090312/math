## 1. 프로젝트 소개

이 프로젝트는 고등학교 2학년 수학 과목인 **미적분Ⅰ**에서 배우는 개념을 정보 기술과 결합하여 탐구하기 위해 제작되었습니다.

수학에서는 함수의 변화 정도를 수식으로 표현할 수 있으며, 특히 미적분Ⅰ에서는 **평균변화율과 미분계수**를 통해 함수가 특정 구간 또는 특정 순간에 얼마나 빠르게 변하는지를 이해할 수 있습니다.

본 탐구에서는 함수

> **f(x) = x²**

를 대상으로 두 점을 연결한 **할선의 기울기**와 한 점에서의 **접선의 기울기**를 비교합니다.

또한 Python과 데이터 시각화 기술을 활용하여 수학적 계산 결과를 그래프로 표현하고, 두 점 사이의 거리 `h`를 변화시키면서 평균변화율이 미분계수에 가까워지는 과정을 직접 관찰할 수 있도록 프로그램을 제작했습니다.

# 2. 탐구 동기

미적분Ⅰ에서 미분계수를 배우면서

> "한 점에서의 변화율을 어떻게 구할 수 있을까?"

라는 질문에서 탐구를 시작했습니다.

두 점 사이의 변화율인 평균변화율은 비교적 쉽게 계산할 수 있지만, 한 점에서의 순간적인 변화율을 구하기 위해서는 두 점 사이의 거리를 점점 작게 만드는 과정이 필요합니다.

이를 단순히 수식으로만 학습하는 것이 아니라, 실제 프로그램을 통해 두 점의 위치와 직선의 변화를 직접 확인한다면 미분계수의 의미를 더욱 명확하게 이해할 수 있을 것이라고 생각했습니다.

따라서 수학적 개념을 정보 기술을 통해 시각화하고, 수식과 그래프가 어떻게 연결되는지 탐구하고자 했습니다.
